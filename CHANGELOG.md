# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-09
### Added
- Chunk-buffered financial ledger ingestion framework using 64KB streaming blocks.
- Thread-safe, reentrant custom field extractor mapping raw column data.
- Automated testing configuration matrix via compiled `Makefile`.
- Robust parsing exceptions firewall isolating malformed structures.
